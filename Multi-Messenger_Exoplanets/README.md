# Repository Structure

The relevant code used to generate each figure is organized into separate folders.

> __Figure_1__
> - ___lisasim_snr.py___: The python script that calculates the SNR residual across the discovery space shown in the figure.  Output saved in the __LISAsim_data_files__ folder.
> - ___residual_SNR.pdf___: The PDF figure.
> - ___snr_residual.ipynb___: The Jupyter Notebook used to generate the residual SNR discovery space plot.


> __Figures_3_4__
> - ___CombinedDetectLimits.pdf___: The PDF Figure 3.
> - ___combined_detection_space.ipynb___: The Jupyter Notebook used to generate Figures 3 and 4.
> - ___distance-reach.pdf___: The PDF Figure 4.


> __LISAsim_data_files__
> - ___lisasim_4yr.h5___: Data saved from the 4 year LISA simulation used in Table 1.
> - ___orbits_equalarm_20350101.h5___: This file contains the data for a LISA orbit that was generated using equal-armlength orbits, given a start time of 2035/01/01.  This orbit information is read in by the LISA simulation scripts in order to perform the LISA simulations.
> - ___snrdiff.txt___: The residual SNR data file output when running the ___lisasim_snr.py___ script.  This data is used to plot __Figure 1__.
> - ___snrdiff_dist.txt___: The residual SNR data file output when running the ___lisasim_snr_dist.py___ script.  This data is used to determine the power law dependencies in the  __power_laws.ipynb__ notebook.
> - ___snrdiff_Tobs.txt___: The residual SNR data file output when running the ___lisasim_snr_Tobs.py___ script.  This data is used to determine the power law dependencies in the  __power_laws.ipynb__ notebook.


> __Table_1__
> - ___lisasim.py___: The python script that runs the LISA simulations to calculate the "Derived System Properties" in Table 1.  Output saved in the __LISAsim_data_files__ folder.
> - ___table_1_calculations.ipynb___: The Jupyter Notebook used to calculate the "Derived System Properties" in Table 1.


> __power_law_study__
> - __lisasim_snr_Tobs.py__: The python script that calculates the SNR residual for a range of observation times.  Output saved in the __LISAsim_data_files__ folder.
> - __lisasim_snr_dist.py__: The python script that calculates the SNR residual for a range of GW source distances.  Output saved in the __LISAsim_data_files__ folder.
> - __power_laws.ipynb__: A Jupyter Notebook for testing the LISA power law relationships.



> ___functions.py___
>
> All of the main functions for the various formulae presented in the paper are contained in this file.  These functions are imported by the other jupyter notebooks and python scripts.



__Important Note__: The .h5 data files for the 7 and 10 year LISA simulations were larger than 100 MB, which is why they are not in the **LISAsim_data_files** folder with the 4 year simulated data file.  However, these can be generated by running the **lisasim.py** script.  The script is currently set-up to generate the 10 year simulation - it just needs to be run and it will output the data file.  It can be modified to run any simulated observation time by changing the `Tobs = ` parameter in the script.  Change the name of the output file accordingly.
